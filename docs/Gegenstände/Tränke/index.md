# Tränke

## Heiltränke

Heiltränke stellen die Lebenspunkte von materiellen Wesen wieder her. Ihre Zubereitung bedarf im Regelfall die Zutat gewonnen durch ein Monster. Heiltränke können mit zunehmender Einnahme Nebeneffekte erzeugen und süchtig machen.
