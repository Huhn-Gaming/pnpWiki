## Biographie

Franz wurde mit zwei seiner Polizisten zur [Frauenkirche](../../../orte/Bayern/N%C3%BCrnberg/Frauenkirche/index.md) gerufen um einen Mord zu ergründen. Dort wurde er sofort von seinem Vorgesetzten [Friedrich Pfeiffer](../../../helden/Friedrich_Pfeiffer/index.md) eingesetzt um den Verdächtigen [August Huber](../../N%C3%BCrnberg/August%20Huber/index.md) festzunehmen.
