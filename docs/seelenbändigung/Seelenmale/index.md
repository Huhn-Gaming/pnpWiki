# Seelenmale

Seelenmale sind Markierungen, welche einem Seelenbänbdiger helfen SEelen zu kontrollieren. Dabei fängt er mit seiner eigene an und meistert so langsam auch die Aufnahme einer anderen Seele.

Ein Seelenmal ist nicht einfach so sichtbar, nur wenn eine Seelenbändigung aktiviert wurde leuchtet das Mal auf und ein weißer Rauch entschwindet. Für die [Custodire](../../gruppierungen/Custodire%20Populum/index.md) ist das Mal an einem Unterarm von einem Seelenbändiger gezeichnet. [Haja Karim](../../personen/Gibraltar/Haja%20Karim/index.md) hat ihres auf der Stirn.

Es heißt sogar, das man ohne ein Mal Seelen bändigen kann, doch glaubt niemand an solche abergläubischen Geschichten.
